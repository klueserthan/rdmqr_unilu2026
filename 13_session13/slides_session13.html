Bivariate Regression

  • Estimates how changes in one variable relate to changes in another
  • Slope shows direction and strength of the relationship
  • Residuals capture what the model does not explain

  • Standard errors reflect precision of the estimates

    • Depend on the association strength, variance of \(X\), and \(n\)
  • p-values indicate whether the relationship differs from zero

Multiple Regression

  • Regression does not only serve to predict the values of \(y\) based on the values of \(x\)
  • The regression model can be extended with additional variables, allowing us to predict the value of \(y\) based on the values of \(x\) and \(z\) (or additional variables)
  • In doing so, the model estimates the relationship between \(x\) and \(y\) while holding \(z\) constant

\[ Y_i = \alpha + \beta_1 X_{1_i} + \beta_2 X_{2_i} + ... + \beta_n X_{n_i} + \varepsilon_i \]

Why Is It Useful?


  • Prediction: if the goal is to predict the values of \(y\), adding more relevant variables can increase the predictive power of the model
  • Causality: when the goal is to estimate a causal effect (ATE), holding other variables constant (i.e., controlling) can alleviate omitted variable bias (OVB) when such variables are confounders

The Maths of Multiple Regression

\[ y = \beta_0 + \beta_1 x + \beta_2 z + \varepsilon \]

Step 1: Auxiliary regression

We first explain \(x\) using \(z\):

\[ x = \pi_0 + \pi_1 z + r \]

Step 2: Use only the unexplained part of \(x\)

We then relate \(y\) to this residual:

\[ y = \alpha_0 + \beta_1 r + u \]

The coefficient \(\beta_1\) here is exactly the same as in the multiple regression above

Multiple Regression Summary

  • Multiple regression removes from \(x\) the variation explained by \(z\)
  • Adding controls can change coefficients because it changes what variation is used
  • This logic extends to any number of regressors
  • Theory determines what should be controlled for; regression is only the tool

Regression Assumptions


Assumption Meaning Applies to
Linearity in parameters The model is linear in the coefficients (not necessarily in the variables) All regression
Random sampling Observations are independently and identically distributed All regression
No perfect multicollinearity Regressors are not exact linear combinations of each other Multiple regression
Zero conditional mean The error term has mean zero conditional on the regressors All regression
Homoskedasticity The error term has constant variance conditional on the regressors All regression (for classical SEs)
No autocorrelation Error terms are uncorrelated across observations All regression (esp. time series)
Normality of errors The error term is normally distributed All regression (small-sample inference only)
No measurement error in regressors Regressors are measured without error All regression
Correct model specification No relevant causal variables omitted and no irrelevant variables included All regression
Regressors must vary Explanatory variables exhibit sufficient variation All regression
n > k Sample size exceeds number of estimated parameters All regression
Conditional independence Given controls, the regressor of interest is independent of unobserved determinants of the outcome Multiple regression (causal interpretation)

Advanced Topics


Topic Brief description
Outliers and influential observations Identifying observations that disproportionately affect regression estimates
Nonlinear relationships Modeling curvature via transformations of variables (e.g. log, square, exponential)
Dummy variables Including categorical predictors using a reference category
Fixed effects Special case of dummy variables controlling for units (e.g. individuals, countries, years)
Standardization Rescaling variables (e.g. mean 0, standard deviation 1) to ease interpretation and comparison of coefficients
Interaction terms Modeling effects that depend on the value of another variable (two-way or higher-order interactions)
Robust standard errors Inference methods that remain valid under heteroskedasticity or clustered errors
Binary dependent variables Models for yes/no outcomes (linear probability model, logit, probit)
Categorical dependent variables Models for nominal or ordinal outcomes (multinomial logit, ordered logit/probit)
Generalized Linear Models (GLM) Unified framework extending linear regression to non-normal outcomes
Complex data structures Time series, panel data, clustered observations
Multilevel (hierarchical) models Modeling nested data structures with varying effects across levels
